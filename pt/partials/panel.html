Cadastre uma VM, vincule um repositório, clique em Deploy. O Cleat provisiona o Caddy e a unit do systemd para você. 

# cadastre o servidor uma vez
cleat servers create --name web-1 --ip 203.0.113.10 --ssh-key-file ~/.ssh/id_ed25519  # imprime o id

# vincule o repositório e faça o deploy
cleat deploy --repo owner/app --server 5 --host app.example.com --watch
