PaaS self-hosted via SSH

Deploy nos seus servidores. Não nos de outra pessoa.

O Cleat é um painel, um CLI e um servidor MCP para fazer deploy de apps Phoenix, Go, Node, Rails, Rust e estáticos via SSH — com push-to-deploy do GitHub.

Como funciona

  1. 01

    git push

    Push na branch vinculada.

  2. 02

    Webhook

    Verificado por HMAC, enfileirado no Oban.

  3. 03

    Build na VM

    Clonado e compilado via SSH.

  4. 04

    Publicar

    Release, systemd e Caddy.

Três formas de usar

Cadastre uma VM, vincule um repositório, clique em Deploy. O Cleat provisiona o Caddy e a unit do systemd para você. 

# cadastre o servidor uma vez
cleat servers create --name web-1 --ip 203.0.113.10 --ssh-key-file ~/.ssh/id_ed25519  # imprime o id

# vincule o repositório e faça o deploy
cleat deploy --repo owner/app --server 5 --host app.example.com --watch
